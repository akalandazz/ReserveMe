# Запись в салон — Telegram Mini App

Мини-приложение для записи к мастеру. React + Vite, без бэкенда.

## Команды

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
npm run lint     # oxlint
```

## Как поменять свои данные

Весь контент — в одном файле [src/data.js](src/data.js). Там русские
комментарии над каждым блоком. Менять нужно как минимум:

| Что | Где |
|---|---|
| Telegram-логин мастера (без `@`) | `MASTER_USERNAME` — **обязательно**, иначе заявки не отправятся. Можно вместо правки файла задать `VITE_MASTER_USERNAME` в `.env` (см. [.env.example](.env.example)) |
| Имя мастера | `MASTER_NAME` |
| Телефон | `MASTER_PHONE` (пустая строка `""` — не показывать) |
| Услуги, цены, длительность | `SERVICES` |
| График работы | `WORKING_HOURS` + `WORKING_HOURS_TEXT` |
| Отпуск и отдельные выходные | `DAYS_OFF` |
| Адрес и ссылка на карту | `LOCATION` |
| Тексты «Важной информации» | `INFO_BLOCKS` |

⚠️ У существующих услуг **нельзя менять `id`** — по нему находятся уже
сохранённые записи клиентов. Название и цену менять можно.

После правок нужна пересборка: `npm run build`.

## Как это работает

Приложение **не имеет сервера**. Когда клиент оформляет заявку:

1. Заявка сохраняется у клиента — в Telegram CloudStorage (привязано к его
   аккаунту, переживает переустановку), с запасным вариантом в localStorage.
2. Открывается чат с мастером с **уже набранным текстом** заявки, который
   клиент отправляет сам.

Подтверждение записи — только ответ мастера в чате.

## Ограничения

- Записи видны только клиенту. Мастер узнаёт о них **из сообщения в чате** —
  это единственный источник истины.
- Список свободного времени скрывает только **собственные** записи клиента.
  Это не общий календарь: двое разных клиентов могут запросить один слот.
- На клиентах Telegram старше версии 6.9 данные живут в localStorage WebView
  и могут быть очищены системой.
- Подстановка текста в чат (`t.me/<username>?text=…`) — поведение deep-link,
  а не документированный API мини-аппов. На некоторых клиентах может не
  сработать, поэтому рядом всегда есть кнопка «Скопировать текст».
- Правка цен требует пересборки и перевыкладки. Если владельцу нужно менять
  их самостоятельно — с этого момента нужен бэкенд.

## Развёртывание

Telegram принимает только **HTTPS**. Для проверки на телефоне:

```bash
npm run dev
npx localtunnel --port 5173   # или ngrok
```

Хост туннеля добавьте в `server.allowedHosts` в [vite.config.js](vite.config.js),
иначе Vite отклонит запрос. Полученный URL пропишите в BotFather:
`/newapp` → выбрать бота → указать ссылку.

Для продакшена соберите `npm run build` и выложите папку `dist/` на любой
статический хостинг с HTTPS.

## Структура

```
src/
  data.js        весь контент — единственный файл для владельца
  schedule.js    даты и свободные слоты (чистые функции)
  storage.js     CloudStorage + localStorage
  telegram.js    обёртка над window.Telegram.WebApp + тексты сообщений
  ui.jsx         Screen / Row / Chip / Card / кнопки
  App.jsx        стек экранов и кнопка «назад»
  screens/       по файлу на пункт меню
```
